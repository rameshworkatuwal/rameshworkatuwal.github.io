# Temporarily paused games

Original games.html, online-ludo.html, site.js and sports.html are preserved here. Game JavaScript, CSS and assets remain in their original locations. No player data was changed.

To restore the games, copy games.html and online-ludo.html to the repository root. Restore or merge the archived site.js navigation and sports.html mode links into the current root files, preserving any subsequent changes. The root game URLs currently redirect to sports.html.
